# Refractory

## Mod bauen

Öffne ein PowerShell-Terminal im Projektordner und führe aus:

```powershell
.\gradlew.bat build
```

Die fertige Mod-Datei wird danach im Ordner `build\libs` abgelegt.

## Testen während der Entwicklung

Um Minecraft mit der Mod in einer Entwicklungsumgebung zu starten, führe aus:

```powershell
.\gradlew.bat runClient
```
